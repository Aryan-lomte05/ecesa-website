# ECESA website

**Website for the Electronics and Computer Engineering Students' Association, K. J. Somaiya School of
Engineering.**

[![React](https://img.shields.io/badge/React-create--react--app-8B7CF6?style=flat-square)](#running-it)
[![Superseded](https://img.shields.io/badge/status-superseded-ef4444?style=flat-square)](#status)

A single page association site: who the council is, what the association does, events and a call to action.

## What is here

Component per section under `src/components/`, each with its own stylesheet: `About`, `CTA`, and the council
group photograph in `src/assets/images/`.

## Running it

```bash
npm install
npm start
npm run build
```

## Status

**Superseded.** This is an early version of the ECESA site, kept for history. Later association work, including
the national Agri-Tech hackathon platform, is in
[AgriTech-E-CESA](https://github.com/Aryan-lomte05/AgriTech-E-CESA).
